Ada IntelliJ Plugin

A proposed plugin that adds Ada support to IntelliJ IDEA and other JetBrains IDEs.

Overview

Ada has mature free tools, including the GNAT compiler and AdaCore's Ada Language Server, but JetBrains IDEs have no official Ada support. This plugin would bring Ada into the same environment many developers already use for other languages, with the editing features people expect: highlighting, completion, navigation, refactoring, and inline diagnostics.

Status: this is a design concept. We did not find an official or published Ada plugin in the JetBrains Marketplace when researching this page.

Planned features

  • Syntax highlighting and code formatting for .ads and .adb files.
  • Code completion, go-to-definition, find usages, and symbol search.
  • Inline errors and warnings from the compiler and language server.
  • Project structure support for GNAT project files (.gpr).
  • Run and debug configurations for Ada executables.

How it might work

The plugin would be a thin layer over existing tools rather than a new Ada compiler. Its parts could be:

  1. File recognition. Register Ada file types and provide a lexer and syntax highlighter for keywords, string and character literals, comments, and attributes.
  2. Language server client. Starts ada_language_server and talks to it over the Language Server Protocol. IntelliJ 2023.2 and later include built-in LSP support, so completion, hover, diagnostics, and navigation can come from the server instead of being reimplemented.
  3. Project model. Read the .gpr project file to find source directories, object directories, and the main subprogram, then pass that information to the server and the run configurations.
  4. Build and run. Wrap gprbuild in IntelliJ build actions, parse its output into the Problems view, and offer a run configuration that starts the built executable.
  5. Debugging (later). Connect to gdb through the IDE's debugger interface once the basics are stable.

Development approach

  • Build with the IntelliJ Platform Gradle plugin and the IntelliJ Platform SDK.
  • Start with highlighting and LSP integration, then add build and run support.
  • Publish to the JetBrains Marketplace once the core features are stable.

Learn more

Read about the language at the Ada Information Clearinghouse and AdaCore's overview of Ada. The companion Alire plugin covers dependency management.
