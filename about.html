About us

This site is a small, independent project exploring developer tools for Ada, a language built for safety-critical and high-integrity software.

Our focus is on the everyday experience of writing Ada: editing, navigating a codebase, managing third-party libraries, and building. Most of the modern tooling people take for granted in other languages is either missing or scattered across command-line tools and separate editors.

What we are working on

  • An IntelliJ IDEA plugin for Ada source files, with syntax highlighting, navigation, and diagnostics. See the plugin overview.
  • An Alire plugin that brings the Alire package manager into the IDE. See the plugin overview.

About Ada

Ada is a general-purpose language standardised by ISO. It is used in aerospace, defence, rail, and other industries where software failures are costly. It includes strong typing, built-in concurrency through tasks and protected objects, and optional run-time checks. The Ada Information Clearinghouse is a good starting point for learning more.

The Alire project maintains a community catalogue of Ada and SPARK libraries, along with the alr command-line tool for fetching and building them.

Our principles

  • Build on existing open tools rather than replacing them.
  • Keep the sites simple and fast, with no tracking.
  • Credit the Ada and Alire communities for the work this project depends on.
