Alire Plugin

A proposed plugin that brings the Alire package manager into the IDE.

Overview

Alire (Ada LIbrary REpository) is a catalogue of Ada and SPARK libraries plus the alr command-line tool. It plays a role similar to Rust's Cargo. Projects describe themselves and their dependencies in an alire.toml manifest, and Alire sets up a project-local environment, including the compiler and any system packages a dependency needs.

The plugin would let developers do these tasks from the IDE, without switching to a terminal.

Status: this is a design concept. Alire's own project has discussed built-in editor setup as a feature request, but we did not find an existing Alire plugin for IntelliJ.

Planned features

  • A tool window listing the project's dependencies, versions, and available updates.
  • Search the Alire index and add a crate with one action, the IDE equivalent of alr with.
  • Edit alire.toml with schema-aware completion and validation.
  • Build, run, and clean actions that call alr build and alr run.
  • Show toolchain and environment status, including whether the GNAT compiler is installed.

How it might work

The plugin would call the alr command-line tool, so it always matches what developers use in a terminal. Its parts could be:

  1. Detection. When a project is opened, look for alire.toml at the project root and enable the Alire features only if it is found.
  2. Command runner. Run alr as a background process, with output sent to an IDE console. Use machine-readable output where alr provides it, and show errors as notifications.
  3. Manifest model. Parse alire.toml to list dependencies and their version constraints. Re-read the file when it changes, so edits made in the editor appear in the tool window straight away.
  4. Index search. Query the Alire catalogue to show available crates and their descriptions, and add the chosen one to the manifest.
  5. Build integration. Connect build and run actions to the IDE's build system. Pass build errors from alr build to the Problems view so they can be clicked in the editor.
  6. Language server setup. Point the Ada language server at the environment that Alire creates, so completion and navigation see the same dependencies the build uses.

Relationship to the Ada IntelliJ plugin

The two plugins are designed to work together. The Ada IntelliJ plugin handles editing and language features. This plugin handles dependencies and builds. If the Alire plugin is used alone, it can still give full build support by running alr directly.
